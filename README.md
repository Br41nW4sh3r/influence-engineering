# [B4W] — Influence Engineering

> I don't hack systems. I hack beliefs.

Influence Engineering is the study of how beliefs are installed, reinforced and exploited.

This is not about hacking machines. This is about hacking minds.

### The Stack
1. **HOOK** - Capture attention in 3 seconds
2. **BELIEF** - Install an idea
3. **PROOF** - Make it feel true
4. **ACTION** - Make them move

### Structure
- `01-frameworks/` - Mental models and persuasion systems
- `02-case-studies/` - Real world analysis of propaganda & manipulation
- `03-tools/` - Small scripts to detect manipulation

### Disclaimer
This repo is for research / defense. Understand how manipulation works to avoid being manipulated.
